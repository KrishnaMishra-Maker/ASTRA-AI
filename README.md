# ASTRA AI 

**AI-Powered Smart Motorcycle Safety and Road Hazard Detection System**

## About the Project
ASTRA AI is a smart motorcycle safety project designed to help riders identify potential road hazards, including potholes, pedestrians, and animals.

## Key Features
- Road hazard detection using ESP32-CAM and sensors
- Audio alerts for the rider
- Vibration-based warning system
- Designed to improve rider awareness and road safety

## Hardware
- ESP32
- Sensors for hazard and motion detection
- Audio alert components
- Vibration motor
- Power supply and supporting electronic components

## Project Status
Currently under development. Hardware integration, testing, and feature implementation are in progress.

## Vision
To make motorcycle journeys safer by providing timely warnings about potential road hazards.
